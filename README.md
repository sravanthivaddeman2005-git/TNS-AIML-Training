# Diabetes Risk Prediction (Learning Project)

This project follows the structure of the HeartDiseasePrediction example:

- `train.py` trains and evaluates the model.
- `dataset/diabetes.csv` is the local training dataset.
- `diabetes_model.joblib` is generated by training.
- `app.py` loads the saved model and shows the Streamlit form.
- `predict.py` runs a command-line example.
- `requirements.txt` lists the Python packages.

## Run in VS Code (Windows)

1. Open this project folder in VS Code.
2. Open **Terminal → New Terminal**. Make sure the prompt ends in `diabetes_risk_project`.
3. Activate the existing virtual environment: ` .\.venv\Scripts\Activate.ps1`
4. Install dependencies: `python -m pip install -r requirements.txt`
5. Train the model: `python train.py`. The script reads the CSV from the local `dataset` folder and saves `diabetes_model.joblib` beside `train.py`.
6. Start the web app: `python -m streamlit run app.py`.

The first training step does not require an internet connection because the dataset is included in `dataset/diabetes.csv`.

This is an educational demonstration using a limited historical dataset. Its score is not a diagnosis or a calibrated estimate of personal medical risk.
